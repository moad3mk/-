# NEXO CLOUD PRIVATE

لوحة تحكم خاصة لإدارة بوتات Discord المبنية بـ Node.js فقط. لا يشمل المشروع استضافة مواقع الويب.

## الحالة الحالية
- الواجهة موجودة في هذا المجلد وتُقدّم من المسار `/cloud/` عبر خادم NEXO الحالي.
- تسجيل الدخول يستخدم كلمة مرور `HOST_PASSWORD` مع جلسة HttpOnly محدودة المدة.
- قائمة البوتات تعرض المجلدات الموجودة على خادم المنصة وحالة العمليات المحلية.
- رفع ملفات ZIP محمي بجلسة الدخول، بحد أقصى 12MB للملف و30MB بعد فك الضغط و250 ملفاً.
- يجب أن يحتوي الأرشيف على `index.js` في جذره. تُرفض المسارات غير الآمنة والروابط الرمزية.
- التشغيل والإيقاف والسجلات متاحة من لوحة التحكم.
- البوت الذي يتم تشغيله من اللوحة يُعاد تشغيله تلقائياً عند إعادة تشغيل الخادم؛ إيقافه يزيل علامة التشغيل التلقائي.
- لا يتم تثبيت مكتبات `package.json` تلقائياً.
- بوت NEXO الحالي على Wispbyte مستقل ولن نغيّر تشغيله أثناء بناء المنصة.

## مراحل التطوير التالية
1. تجهيز عزل آمن لعمليات البوتات وحدود موارد مستقلة.
2. تثبيت اعتماديات البوتات بعد تجهيز العزل.
3. مدير ملفات ومتغيرات بيئة سرية لكل بوت.
4. مراقبة استهلاك الموارد وتحسين السجلات.

## الأمان والاستضافة
شغّل فقط ملفات بوتات تثق في مصدرها. عمليات البوتات تعمل حالياً بصلاحيات حساب نظام الخادم، لذلك لا تشغّل ملفات مجهولة أو غير موثوقة. يجب تجهيز عزل حقيقي قبل السماح بتثبيت اعتماديات أو تشغيل كود غير موثوق.

الخطة تستهدف حلولاً مجانية قدر الإمكان، لكن لا يوجد ضمان لاستضافة مجانية تعمل 24/7 دون انقطاع؛ ذلك يعتمد على مزود الاستضافة وسياساته وحدوده.
