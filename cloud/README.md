# NEXO CLOUD PRIVATE

لوحة تحكم خاصة لإدارة بوتات Discord وتطبيقات البوتات المبنية بـ Node.js فقط. لا يشمل المشروع استضافة مواقع الويب.

## الحالة الحالية
- الواجهة موجودة في هذا المجلد.
- يتم تقديمها من المسار `/cloud/` عبر خادم NEXO الحالي.
- واجهة التحكم ما زالت أولية؛ لم يتم بعد ربطها بتسجيل دخول آمن أو API إدارة البوتات.
- بوت NEXO الحالي على Wispbyte مستقل ولن نغيّر تشغيله أثناء بناء المنصة.

## مراحل التطوير
1. تسجيل دخول آمن للوحة دون كشف كلمة المرور في المتصفح.
2. ربط قائمة البوتات وحالاتها الفعلية.
3. تشغيل وإيقاف وإعادة تشغيل البوتات من اللوحة.
4. مدير ملفات ومتغيرات بيئة سرية لكل بوت.
5. سجلات التشغيل والأخطاء ومراقبة الموارد.
6. عزل عمليات البوتات ووضع حدود للموارد وحماية الملفات.

## الأمان والاستضافة
يجب تشغيل كل بوت كعملية منفصلة مع التحقق من المسارات والصلاحيات وحدود الموارد. لا يجوز تشغيل ملفات يرفعها المستخدم داخل عملية لوحة التحكم نفسها.

الخطة تستهدف حلولاً مجانية قدر الإمكان، لكن لا يوجد ضمان لاستضافة مجانية تعمل 24/7 دون انقطاع؛ ذلك يعتمد على مزود الاستضافة وسياساته وحدوده.
