# NEXO PRIVATE HOST

لوحة خاصة لإدارة وتشغيل بوتات Discord المكتوبة بـ Node.js.

## التشغيل

1. استخدم استضافة أو خادماً يدعم Node.js 20 أو أحدث ويظل يعمل باستمرار.
2. ثبّت الاعتماديات: `npm install`
3. اضبط متغير البيئة السري `HOST_PASSWORD` بكلمة مرور قوية.
4. شغّل التطبيق: `npm start`
5. افتح رابط التطبيق وسجّل الدخول بكلمة المرور نفسها.

## إضافة بوت

أنشئ مجلداً لكل بوت داخل `bots/`، مثلاً `bots/my-bot/`، وضع ملف التشغيل باسم `index.js` داخله. ضع توكن Discord وأي أسرار أخرى في متغيرات البيئة على الخادم، ولا تكتبها داخل الملفات أو ترفعها إلى GitHub.

مثال:
```
bots/
  my-bot/
    index.js
```

كل بوت يعمل من مجلده الخاص، وتظهر حالته وسجلاته في اللوحة.

## تنبيه مهم

GitHub يحفظ الكود فقط ولا يشغّل البوتات 24/7. يلزم ربط هذا المشروع بخادم Node.js فعلي. توفر التشغيل المجاني المستمر يعتمد على شروط وموارد مزود الاستضافة؛ هذا المستودع وحده لا يوفر خادماً.
