# NEXO CLOUD PRIVATE

مشروع لوحة تحكم خاصة لإدارة مشاريع Node.js وبوتات Discord ومواقع الويب.

## الحالة الحالية
هذه مجلد مستقل داخل المستودع الحالي حتى لا نغيّر أو نوقف NEXO PRIVATE HOST أو بوت NEXO الحالي. يحتوي حالياً على واجهة تأسيسية فقط؛ أزرار التشغيل وإدارة الملفات والعمليات الخلفية لم تُربط بعد.

## خطة التنفيذ
1. واجهة لوحة التحكم.
2. مصادقة آمنة وحساب مدير.
3. API لإدارة المشاريع وسجلات التشغيل.
4. عامل تشغيل منفصل لكل مشروع مع حدود موارد.
5. نسخ احتياطي ومراقبة وإعادة تشغيل عند الأعطال.

## ملاحظة الاستضافة
الواجهة وحدها لا توفر استضافة دائمة. استمرارية التشغيل تعتمد على مزود الاستضافة وحدوده وسياساته؛ لا يوجد ضمان 24/7 مجاني مطلق.
