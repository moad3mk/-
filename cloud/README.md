# NEXO CLOUD PRIVATE

لوحة خاصة لإدارة بوتات Discord المبنية بـ Node.js فقط. لا يشمل المشروع استضافة مواقع الويب.

## الموجود حالياً
- دخول خاص بكلمة مرور `HOST_PASSWORD` وجلسة HttpOnly.
- رفع ZIP مع حدود للحجم وعدد الملفات وفحص المسارات.
- عرض البوتات وحالتها، وتشغيلها وإيقافها من اللوحة.
- عرض آخر سجلات كل بوت.
- تشغيل تلقائي بعد إعادة تشغيل الخادم للبوتات التي تم تشغيلها من اللوحة.
- متغيرات بيئة منفصلة لكل بوت، تحفظ في ملف `.nexo-env.json` بصلاحيات ملفات مقيدة.
- لا يتم تمرير متغير `HOST_PASSWORD` أو بقية بيئة الخادم كاملة إلى عمليات البوتات؛ تمرر فقط متغيرات نظام أساسية ومتغيرات البوت المحددة.

## حدود الأمان المهمة
الرابط الخاص وعدم نشره يقللان الوصول للوحة، لكنهما لا يعزلان كود البوتات. عمليات البوتات تعمل حالياً تحت حساب نظام التشغيل نفسه الذي يشغّل لوحة التحكم، وقد يتمكن كود بوت خبيث من قراءة ملفات بوتات أخرى أو ملفات الخادم التي يستطيع الحساب الوصول إليها. لذلك شغّل فقط بوتات موثوقة، ولا تعتبر متغيرات البيئة حماية كاملة بين زبون وآخر.

قبل قبول بوتات من زبائن لا تثق بكودهم، يجب نقل كل بوت إلى حاوية أو مستخدم نظام مستقل مع حدود CPU/RAM/التخزين والشبكة، وتثبيت اعتمادياته داخل بيئته المعزولة. تثبيت `package.json` ما زال معطلاً حالياً لهذا السبب.

## الاستضافة
الخطة تستهدف حلولاً مجانية قدر الإمكان، لكن لا يوجد ضمان لاستضافة مجانية تعمل 24/7 دون انقطاع؛ ذلك يعتمد على مزود الاستضافة وسياساته وحدوده.
